# Юридические страницы сайта ТуДулиКо Россия

Готовые HTML/CSS для каталога сайта:

`rafadelya.github.io/projects/ToDooliCo/ToDooliCo_Russia/Legal/`

Текст синхронизирован с `assets/law/*.md` приложения (редакция 10 ноября 2026).

## Установка на сайт

```bash
cp -f ~/Desktop/ToDooliCo/website/Legal/{privacy.html,terms.html,legal.css,Privacy_policy.txt} \
  ~/Downloads/rafadelya.github.io-main/projects/ToDooliCo/ToDooliCo_Russia/Legal/
```

Открыть локально:

- `.../Legal/privacy.html`
- `.../Legal/terms.html`

## Оформление

- системный шрифт, читательская колонка;
- оглавление с якорями;
- светлая и тёмная тема через `prefers-color-scheme`;
- без карточек, эмодзи и аккордеонов;
- юридическая нумерация пунктов сохранена.
